# ANT COLONY OPTIMIZATION BASED FACTORIZED‑PHEROMONE ELLIPSE DETECTION ALGORITHM FOR NOISY PARTIAL‑ARC MONTE‑CARLO COMPTON‑SCATTERING DATASETS
This research provides several significant contributions to the fields of computational imaging and meta-heuristic optimization. By addressing the specific challenges of high-noise environments, the work moves beyond standard geometric detection to offer the following advancements:
i.	Factorized Pheromone Model: The work introduces a novel Ant Colony Optimization (ACO) based Factorized Pheromone Ellipse Detection (FPED) algorithm. Unlike traditional ACO methods that use a single pheromone matrix, this approach models pheromone trails independently for each ellipse parameter (center coordinates, semi-axes, and orientation), which mitigates combinatorial explosion and improves convergence in noisy environments.
ii.	Specialized Application to Compton Scattering: The research addresses a specific research gap by adapting ellipse detection for Monte Carlo simulated Compton scattering datasets. It is designed to handle probabilistic photon interaction data and partial-arc signatures that traditional methods like Hough and RANSAC struggle to process.
iii.	Enhanced Fitness Evaluation Strategy: A new fitness function was developed based on geometric consistency and residual arc fitting error to accurately guide the algorithm in fitting ellipses to partial arc data.
iv.	Computational Efficiency for Embedded Systems: The study aims to reduce computational burden, making the algorithm suitable for real-time systems, FPGAs, and high-throughput environments. Preliminary results indicate an exceptionally fast average processing time of 0.2 ms per image.
v.	Improved Detection Metrics: The work demonstrates high precision and robustness, achieving an 82.4% pass rate (IoU ≥ 0.7) and very low Mean Absolute Error (MAE) across all ellipse parameters in simulated evaluations.
